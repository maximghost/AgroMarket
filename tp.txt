TP : Réalisation d’une plateforme E-commerce de mets
locaux
1. Objectif pédagogique
Créer une plateforme permettant :
- la vente de mets locaux par commune (attiéké, gari, huile
rouge, etc.);
- la traçabilité des produits agricoles;
- la mise en relation producteurs,consommateurs et
exportateurs
2. Organisation du TP
Les étudiants sont répartis en deux groupes :
- Groupe 1 : Designers (UX/UI)
- Groupe 2 : Développeurs (Technique)
La collaboration entre les groupes est obligatoire.
Groupe 1 : Designers (UX/UI)
Analyse utilisateur
Identifier les profils :
 Clients urbains;
Clients ruraux;
Diaspora;
Exportateurs;
Producteurs et cooperatives.
Livrable : 3 personas
Parcours utilisateur
Modéliser les parcours :
- Achat de produit
- Vérification de la traçabilité
- Commande et paiement
Livrable : User flow
2
Maquettes
Réaliser les interfaces suivantes :
- Accueil
- Catalogue
- Fiche produit avec traçabilité
- Panier
- Paiement
- Dashboard producteur
Ergonomie
Contraintes :
- Mobile first
- Simplicité d’utilisation
- Performance
Livrable : justification UX
Groupe 2 : Développeurs
3. Technologies recommandés ou autres
Frontend : React ou Vue
Backend : Node.js ou Django
Base de données : PostgreSQL ou MongoDB
Fonctionnalités
- Authentification (client / producteur)
- Gestion des produits
- Module de traçabilité
- Panier et commande
- Dashboard producteur
API
Endpoints requis :
/products
/orders
3
/users
/traceability
4. Collaboration Designers / Développeurs
- Validation des maquettes avant développement
- Tests utilisateurs
- Itérations
5. Livrables finaux
Designers : Personas, User flow, Maquettes, Argumentaire UX
Développeurs : Code, API documentée, Démo
Commun : Pitch + démonstration
6. Critères d’évaluation
Utilité réelle : 25%
UX/UI : 20%
Technique : 25%
Innovation : 20%
Cohérence : 10%
